# Project image folders

Create one folder per production using a short lowercase name with hyphens, then keep that show's images together:

```text
assets/images/projects/
  a-midsummer-nights-dream/
    cover.jpg
    01.jpg
    02.jpg
  the-crucible/
    cover.jpg
    01.jpg
```

Use `cover.jpg` for the front-page tile. Add the paths to the matching entry in `../../js/projects.js`. JPG or WebP images work well; keep filenames lowercase and avoid spaces.
